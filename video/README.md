# Ролик SaveHub

Ролик на 1–2 минуты для защиты, собранный в [Remotion](https://www.remotion.dev/)
(монтаж кодом на React). Сценарий, подписи и тайминги — в `src/shots.ts`.

```bash
cd video
npm ci
npm run dev       # Remotion Studio: превью в браузере
npm run check     # проверка типов
npm run render    # итоговый ролик в out/savehub.mp4 (записи экрана ускорены в SPEED раз, см. src/Root.tsx)
```

## Футаж

Файлы лежат в `public/footage/` и хранятся в **Git LFS** — перед работой
выполните `git lfs install` (один раз) и `git lfs pull`. Имена — как в
`src/shots.ts` (`01-add-game.mp4`, `02-profiles.mp4`, …). Пока кадра нет,
вместо него показывается заглушка с описанием, что снимать.

Когда файл готов: поставьте у кадра `ready: true` и подберите `from` (с какой
секунды файла начинать) и `duration` (сколько секунд показывать).

Запись: OBS, 1920×1080, 30 fps, постоянная частота кадров, MP4 (H.264).
Игру — в режиме «окно без рамки», иначе уведомление о снимке может не показаться.
Не допускайте в кадре токенов и личных данных.
