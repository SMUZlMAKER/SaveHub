# Символические ссылки

В Windows символическую ссылку можно создать только при наличии `SeCreateSymbolicLinkPrivilege`, которая по умолчанию есть только у администратора.

Решение - junction (`mklink /J target_link src`). Более ограниченный, чем символические ссылки, но под наши сценарии подходит.

В стандартной библиотеке Rust нет системного вызова junction, поэтому - [сторонняя библиотека](https://github.com/tesuji/junction). Вдобавок ко всему, эта библиотека резолвит относительные пути в абсолютные за нас.
